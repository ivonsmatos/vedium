# 56 — Language Page: SEO Contract (Fase D)

O SEO das páginas de Idiomas é o pilar de tráfego de curso (bottom funnel) da
Vedium. Nenhuma substituição de rota pública acontecerá até a tabela abaixo 
estar 100% verde entre as páginas `CURRENT` e `V2`.

## SEO Checklist para Substituição
Antes de tornar a V2 oficial para qualquer idioma:

- [ ] **URL preservada**: `/curso-de-ioruba-online` se mantém a mesma.
- [ ] **Title & Description**: Recuperados ou superados.
- [ ] **Canonical**: Aponta corretamente para a própria página.
- [ ] **Hreflang**: Respeitar se houver para o curso (PLE, por ex.).
- [ ] **H1 único e descritivo**: Presente e semanticamente acima das `h2`.
- [ ] **Internal Links**: Links para os níveis filhos não podem ser quebrados.
- [ ] **Schema Markup**: `BreadcrumbList` validado e `Course` preservado.
- [ ] **Word/Content Coverage**: FAQs, e descrições mantêm a profundidade.

Durante a Fase D, o piloto Iorubá está isolado em `/_language_ioruba_v2` 
com a meta tag `noindex, nofollow`, sem acesso orgânico.
