Portugiesisch für Ausländer

Erfahren Sie Ihr Niveau in brasilianischem Portugiesisch, bevor Sie mit dem Unterricht beginnen

Diese Bewertung kombiniert Grammatik, Wortschatz, Lesen, simuliertes Hörverständnis, Schreiben und mündlichen Ausdruck. Die Multiple-Choice-Fragen sind auf Portugiesisch — da dies die geprüfte Sprache ist —, aber alle Anweisungen auf dieser Seite sind auf Deutsch. Die objektiven Antworten ergeben eine GER-Einschätzung von A1 bis C1, und die offenen Antworten helfen dem Vedium-Team, Ihr Profil vor der Anmeldung zu bestätigen.

So funktioniert es: Beantworten Sie alle Multiple-Choice-Fragen, um Ihr automatisches Ergebnis freizuschalten. Es wird empfohlen, auch die schriftlichen und mündlichen Antworten auszufüllen, besonders wenn Sie eine genauere Einschätzung für das Leben, Arbeiten oder Geschäfte auf Portugiesisch möchten.

Bevorzugen Sie Anweisungen auf Portugiesisch? Sehen Sie sich die portugiesische Version dieses Tests an.
