Vedium-Empfehlungsprogramm

Empfehlen Sie Vedium weiter, und beide gewinnen: Ihre Freundin oder Ihr Freund erhält bei der Anmeldung automatisch einen Rabatt, und Sie bekommen einen Belohnungsgutschein, sobald die Anmeldung bestätigt ist. Alles wird in einem Dashboard innerhalb der Plattform nachverfolgt.

  • Jede eingeloggte Person hat einen eigenen, automatisch generierten Empfehlungscode.
  • Der Rabatt wird direkt beim Checkout angewendet, ganz ohne manuelle Freigabe.
  • Ihre Belohnung kommt per E-Mail, sobald die Anmeldung bestätigt ist — der Gutschein ist sofort einsatzbereit.

So funktioniert es

Automatische Empfehlungen, direkt in der Plattform

Ablauf

Sie rufen "Meine Empfehlungen" in der Plattform auf und teilen Ihren Code mit einer Freundin oder einem Freund. Meldet diese Person sich mit Ihrem Code an, wird der Rabatt automatisch beim Checkout angewendet, und Ihre Belohnung wird generiert und Ihnen per E-Mail zugesendet — ganz ohne Wartezeit.

Das vollständige Dashboard mit Ihrem Code und dem Verlauf Ihrer Empfehlungen finden Sie unter "Meine Empfehlungen" im eingeloggten Bereich.

1

Code abrufen

Loggen Sie sich ein, öffnen Sie "Meine Empfehlungen" und teilen Sie Ihren persönlichen Link mit Freunden.

2

Automatischer Rabatt

Ihre Freundin oder Ihr Freund gibt den Code beim Checkout ein, und der Rabatt wird sofort angewendet — ohne manuelle Freigabe.

3

Belohnung per E-Mail

Sobald die Anmeldung bestätigt ist, erhalten Sie automatisch einen Belohnungsgutschein.

Wichtige Regeln

Jede empfohlene Person löst nur einmal eine Belohnung für die werbende Person aus, selbst wenn derselbe Code erneut bei einem anderen Kauf verwendet wird.
Niemand darf den eigenen Empfehlungscode verwenden.
Der Belohnungsgutschein ist 180 Tage ab Ausstellung gültig.
