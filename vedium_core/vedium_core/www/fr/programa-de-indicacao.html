Programme de Parrainage Vedium

Recommandez Vedium à vos amis et gagnez tous les deux : votre ami reçoit une réduction automatique sur son inscription, et vous recevez un bon de récompense dès que son inscription est confirmée. Tout est suivi dans un tableau de bord au sein de la plateforme.

  • Chaque étudiant connecté a son propre code de parrainage, généré automatiquement.
  • La réduction de votre ami s'applique directement au paiement, sans approbation manuelle nécessaire.
  • Votre récompense arrive par e-mail dès que l'inscription est confirmée, avec le bon prêt à utiliser.

Comment ça marche

Parrainage automatique, au sein de la plateforme

Le déroulement

Vous accédez à « Mes parrainages » sur la plateforme et partagez votre code avec un ami. Quand il s'inscrit avec votre code, la réduction s'applique automatiquement à son paiement, et votre récompense est générée et envoyée par e-mail, sans attente.

Le tableau de bord complet, avec votre code et l'historique de vos parrainages, se trouve dans « Mes parrainages » dans l'espace connecté.

1

Obtenez votre code

Connectez-vous, accédez à « Mes parrainages » et partagez votre lien unique avec des amis.

2

Réduction automatique

Votre ami utilise le code au paiement et la réduction s'applique instantanément, sans approbation manuelle.

3

Récompense par e-mail

Dès que l'inscription est confirmée, vous recevez automatiquement un bon de récompense.

Règles importantes

Chaque personne parrainée ne génère une récompense qu'une seule fois pour le parrain, même si elle réutilise le même code pour un autre achat.
Personne ne peut utiliser son propre code de parrainage.
Le bon de récompense est valable 180 jours à compter de son émission.
